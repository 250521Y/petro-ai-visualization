# AI研读与同页联动 · 4.1.0

本功能覆盖63个案例、全部61个场景。保留原算法和评价口径，通过同一套当前参数连接操作、图形与结果。

## 课堂展示方式

1. 在案例库搜索并打开案例，选择“案例演示”。演示直接进入实验区，输入与结果放在同一页，顶部“同页联动”条显示本次指标变化。
2. 需要集中展示时点击“放大实验台”。通过“收起实验台”或未打开手册时按Esc返回。
3. 点击右下角书籍按钮，打开当前案例的研读手册。
4. 在What调整参数，切换三个证据图，并点击六步流程阅读本步骤。参数直接进入原实验计算，图表和评价同步变化。
5. 切换Why，说明原任务的困难、方法介入后的作用，并核对当前结果。切换How，串联输入、特征、计算、可视化输出与误差复核。
6. 关闭手册后，当前参数和结果保留。背景或流程页打开的手册关闭后恢复原页；放大实验台内打开的手册关闭后回到放大实验台。

## 三个章节的内容

|章节|要回答的问题|页面中的证据|
|---|---|---|
|What|这个案例实际运行了什么方法？|具体方法名、真实参数、三个专用证据视图、六步解读|
|Why|为什么需要该方法，改善哪部分工作？|任务困难与方法作用对照、当前评价；不虚构现场提速倍数|
|How|输入如何经过计算，改变工程场景中的结果？|逐例六步、当前输入、运行指标、尝试建议及边界|

## 各类算法的特色

- 近邻回归与分类：训练特征空间、当前近邻、权重或投票，以及留出误差或混淆矩阵。
- 回归与软测量：响应切片、当前输入的作用、预测与参考及留出残差。
- 图像分割：像素概率、阈值掩膜、误检漏检、与单属性基线的比较。
- 预测与控制：当前预测窗口、不同跨度误差、正则参数选择，或反馈状态和动作代价。
- 优化：训练代理、可行候选与Pareto取舍、预算约束及代理误差。
- 异常检测：正常背景、多路信号、累积证据、阈值和误报或发现延迟。
- 分段与滤波：多曲线边界、分段重建与界面误差，或学到的滤波权重与同窗基线。
- 文本与知识方法：可见词项及贡献、原文字段与来源、规则排除理由和缺项或无解状态。

这些方法的名称来自当前实现。规则排序、统计检测、信息抽取与模板写作均按其实际机制说明，不声称使用了未接入的大模型或深度网络。数据为教学合成或虚构，评价与现场验证的边界维持逐例说明。
