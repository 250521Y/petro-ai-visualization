# 智绘油程 · 石油工程AI可视化平台源码

**本文件所在的“井见实验平台源代码”就是完整、可编辑的网站源代码文件夹。**

项目名称为“智绘油程 · 石油工程AI可视化平台”，“智”代表AI方法，“绘”体现可视化，“油程”对应石油工程全流程，完整覆盖13个环节、61个场景。首页已移除课程分组覆盖检查与学号输入板块。网页品牌、浏览器标题、首页介绍和独立案例页标题统一使用新名称；源代码与交付目录路径保留，便于继续维护。

当前版本4.1.0，共63个预置交互案例，覆盖全部61个场景和13个工程环节。保留原18例，新增44个场景案例及1个p2误差与区间拓展案例。每例6步、每步1张指导图，共378张。全部案例都有专业背景、案例流程、同页联动实验及What / Why / How研读手册。

网站使用HTML、CSS、JavaScript，计算在浏览器中执行，无需业务后端或数据库。数据均为教学合成或虚构，实际方法、评价口径与适用边界逐例说明。

## 运行与部署

- 直接打开本目录index.html，或双击上一级“结课报告/启动网站.bat”进行本机预览。
- 63例默认注册。新增45例的独立入口引用本源码中的assets/lab，请保持完整源码结构。
- 上一级“63个案例压缩包”内的63个正式ZIP已带齐所需运行文件，解压后打开demo/index.html即可独立演示，也可整包导入主站。
- 上传宝塔使用上一级“宝塔部署_63案例完整版_20261103”。把其内部index.html、assets、cases、examples、docs一起上传至站点根目录。本地部署文件已更新，远程服务器尚未自动更新。

## 修改与同步

原18例保留专用代码，可直接修改cases/对应案例。新增45例的文字、输入、目标与对照优先修改tools/curriculum.cjs；通用流程与配图生成在tools/build-cases.cjs，算法在assets/lab/core.js，界面在ui.js。

在本源码目录依次运行：

```powershell
node tools/build-cases.cjs
node tools/package.cjs
node tools/check.cjs
node tools/check-learning.cjs
node tools/check-packages.cjs
```

生成工具会覆盖新增45例的生成内容。直接修改其case.json或demo.js时，应同步修改内容源，避免重新生成丢失。修改独立案例后须重新打包，主站默认内容才会更新。

共用运行层在源码中只维护一份；打包时加入每个独立ZIP，保证单包便携。源码和部署目录分别用于编辑和上传，应各自完整保留。

## 同页实验与AI研读

63例进入“案例演示”后直接展示交互实验。参数、主图和当前评价集中在同一实验台，顶部“同页联动”条提示本次指标变化；桌面布局把输入与结果并排，小屏保持在当前页内查看。“放大实验台”用于集中演示，可用“收起实验台”返回。

案例页右下角的书籍按钮打开当前案例的研读弹窗。What说明实际方法，提供两个以内的真实参数、三个各具算法特色的运行图表及六步解读；Why说明任务困难、方法介入点和当前可核对结果；How串联输入、处理、输出、评价及适用边界。调整弹窗参数会驱动原实验计算，关闭后保留结果；Esc关闭弹窗，原有页面与滚动位置恢复。在放大实验台内关闭手册，会返回放大实验。

研读资料源在tools/build-learning-guide.cjs：原18例采用专用图表绑定，新增45例引用tools/curriculum.cjs的实际方法内容。运行package.cjs时自动更新，无需另行执行生成。请同步修改内容源，勿仅修改生成的learning-guide.js。方法更换时同时更新三个图表选择器及输入控件ID。

研读手册按实际实现表述：学习回归、近邻分类、分割、异常检测等逐例说明；规则、统计方法、模板和检索不被改称为深度学习或大模型。当前结果用于教学解释，未测量的现场提速倍数不作展示。使用详情见docs/AI研读与同页联动.md。

## 导入与旧材料

案例库提供全站案例搜索，覆盖预置和本机导入案例的标题、场景、工程环节、方法、背景与流程。多个关键词以空格分隔，同时匹配；支持英文大小写及全角兼容、中文标题简称、环节与技术类别组合筛选。搜索条件保存在当前页面地址中，刷新或打开案例后返回仍能恢复。

首页“按环节找”与“作业链”页共用一张石油领域场景式流程图。13个环节分别由露头与地质锤、震源车与检波器、钻井井架、录井仪器房、测井绞车、注水泥车、采油树、井下射孔器、抽油机、修井机、增采泵车、集输管线和炼化装置代表。绿色路线按编号连续连接，点击装置、名称或节点可进入`#/cases?stage=环节ID`对应案例列表。图中案例数来自当前注册表，支持本机导入内容。SVG直接在源码中编辑，不依赖外网图片；键盘可聚焦并回车进入，小屏在图内横向滚动。

“＋ 添加案例”支持文件、文件夹和普通ZIP，三个按钮默认同色，悬停或聚焦时当前按钮变色。单包及解压后总大小均不超过6MB；RAR、7Z、加密、分卷与ZIP64需先转换为普通ZIP。导入记录只保存在当前浏览器。

提交文档已更新为“智绘油程结课报告.pdf”和“智绘油程关键亮点.pdf”，位于上一级“井见可视化实验室交付/03_文档”，均以作者第一人称介绍当前63例、61场景、13环节和378张指导图。对应旧版PDF与中间稿已移除。原始课程资料移至“参考资料”，历史视频与仍可用的答辩配图保留；过时答辩文稿和18例总览图已移除。

63个独立案例ZIP统一放在项目根目录“63个案例压缩包”，按“大类别-小类别.zip”命名。大类别为13个工程环节，小类别为对应场景；同一场景的不同案例在小类别后用括号说明，保证63个案例各有独立文件且不重名。
