# 方法与评价说明

新增45例使用浏览器内透明教学算法，不依赖外部接口或预训练权重。目录描述可研究的技术方向；案例中的“实际方法”说明本演示真正实现的计算。输入、风险阈值、响应与记录均为教学合成或虚构。

|任务|实际计算与评价|
|---|---|
|回归|84条训练、24条校准、36条测试，按合成对象分组。二次特征岭回归，标准化只拟合训练数据；同测试集比较模型与训练均值基线，计量校正用未校读数作基线。|
|区间拓展|wo5与p2拓展用24条校准绝对残差的第ceil(25×0.9)顺序统计量形成区间，再报告36条测试覆盖率。真实资料的可交换性须另验，名义90%不是现场保证。|
|分类|162条训练、54条留出，按完整对象分组。三维标准化距离、k近邻投票和独立混淆矩阵。票比不是校准概率。|
|分割|6个属性图块训练、2块测试，每块32×20像素。逻辑回归分数经阈值产生掩膜；报告IoU、误检、漏检和单属性基线。未训练U-Net或三维网络。|
|分段|96样点三曲线标准化，动态规划最小化段内误差和界面惩罚，最短段6样点。参考界面只评价，±3样点一对一匹配。|
|预警|前45条正常数据拟合尺度，随后累计偏离。事件起点90仅评价；正常期报警样点不等于独立事故数。|
|初至拾取|8条完整道训练、4条道测试。加权窗口逻辑回归与首越阈值拾取；未拾取单独报告，中心窗口不是严格实时。|
|学习去噪|6条道训练五点FIR、2条道测试；与同窗移动平均及未处理波形同位置比较。合成波形机制不代表真实资料。|
|优选|训练代理后枚举289个候选，先筛教学预算和风险，再比较响应与代价。允许无解，保留非支配方案；参考响应不替代搜索模型。|
|控制|135条转移训练、45条测试。每步搜索49个两步动作序列，执行首动作再反馈；同一系统和扰动下比较固定比例基线。实际方法不是强化学习。|
|文本与知识|录井报告为实体抽取与模板，缺项不编造；打捞选型为知识规则与属性检索，先检查适用性；化验审核为单位范围规则与稳健Z，保留原值。|

`node tools/check.cjs`检查63例注册、61场景覆盖、378张指导图及45例默认、对照和参数端点运行。浏览器另检查步骤切换、参数更新和主站内嵌运行。

## 方法参考

- [scikit-learn最近邻文档](https://scikit-learn.org/stable/modules/neighbors.html)：分类投票机制参考。本网站由JavaScript自行实现，不包含该库。
- [scikit-learn逻辑回归文档](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)：逻辑分类模型定义参考。
- [NIST CUSUM递推定义](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/cusum.htm)：本例以多变量偏离强度输入单侧累计，属于教学变体，未使用工业控制限标定。
- [Angelopoulos与Bates的Conformal Prediction入门论文](https://arxiv.org/abs/2107.07511)：独立校准分数、有限样本分位数及覆盖条件参考。

方法参考不为本网站的合成工程响应、教学阈值或生产效果背书。
