# 智绘油程 · 石油工程 AI 可视化平台

面向石油工程教学的交互可视化实验平台。用 **63 个交互案例**覆盖 **13 个工程环节、61 个场景**，结合参数调节、图表联动与 What / Why / How 研读手册，展示实际算法的输入、处理、输出和适用边界。

当前内容版本：**4.1.0**。

## 功能

- **全流程案例库**：地质、地震、钻井、录井、测井、固井、完井、射孔、采油、修井、增产、集输与炼化。
- **同页联动实验**：调整参数后同步查看主图、评价指标和变化反馈，可放大实验台。
- **AI 研读手册**：63 份 What / Why / How 手册、189 个图表绑定，以及 378 张可编辑 SVG 步骤指导图。
- **案例搜索与筛选**：按工程环节、技术类别及多个关键词检索，支持本机导入的案例。
- **案例导入与导出**：支持文件、文件夹和普通 ZIP，导入内容保存在当前浏览器。
- **纯静态运行**：HTML、CSS、JavaScript 实现，计算在浏览器中执行，无需数据库、业务后端、外部 AI 接口或 API 密钥。

## 快速开始

下载源码后，直接用现代浏览器打开根目录的 `index.html` 即可。

也可以在仓库根目录启动本地静态服务（需要 Python 3）：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8000>。若系统使用 `python3` 命令，将上面的 `python` 替换为 `python3`。

部署到静态托管或宝塔站点时，将 `index.html`、`assets/`、`cases/`、`examples/` 和 `docs/` 上传到站点根目录，并保持相对目录结构。

## 校验与维护

运行现有校验需要 Node.js，无需安装 npm 依赖：

```bash
node tools/check.cjs
node tools/check-learning.cjs
```

检查包括案例注册、场景覆盖、指导图、算法默认/对照/参数端点运行、搜索，以及研读手册和图表绑定。

维护时，原 18 例在 `cases/` 中保留专用实现；新增 45 例的内容源位于 `tools/curriculum.cjs`，共用算法位于 `assets/lab/core.js`。生成内容应修改其内容源后再生成。

```bash
node tools/build-cases.cjs
node tools/package.cjs
node tools/check.cjs
node tools/check-learning.cjs
node tools/check-packages.cjs
```

`package.cjs` 会刷新研读资料和默认注册包，并在仓库上一级生成 63 个独立 ZIP、部署目录、源码备份和交付清单。`check-packages.cjs` 用于检查这些生成的交付成果。生成操作会覆盖相应的生成文件，运行前请先保存修改。

## 数据与使用边界

案例数据为教学合成或虚构数据。页面逐例说明实际实现的方法；规则、统计、模板和检索方法按其实际实现描述。教学结果不能直接用于真实油田生产决策，实际部署需另行验证数据、模型和工程条件。

管理入口是纯前端的本机演示功能，默认演示账号为 `admin / admin123`。账号、导入数据和管理改动仅保存在当前浏览器，其登录界面不提供服务端访问控制。公开静态站点中的源码和预置数据对访问者可见。
