术语速查 · 看图理解，再用类比记住

选择术语，在中间切换两种状态，观察图形怎样变化。所有数值和结构均为教学示意。

产量与递减

01 / 名词定义

产量表示单位时间内产出的数量；递减描述其总体下降趋势。本例单位为“教学产量单位/日”，不对应真实油井产量，波动也不自动意味着故障。

02 / 可视化演示

横轴时间、纵轴教学产量。整体下降趋势与短期波动可以同时存在，某一天回升并不否定长期递减。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像电池整体逐渐耗电，但瞬时用电量会随你打开的应用变化。长期趋势和短时起伏需要分开看。

滞后特征与滚动均值

01 / 名词定义

预测第t天时，1日滞后取第t−1天，7日滞后取第t−7天；过去7日均值只取t−7到t−1。窗口不能包含目标日或未来观测。

02 / 可视化演示

目标是第8天。1日滞后只取第7天；过去3日均值取第5、6、7天，绝不能把第8天的真实结果算进去。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像猜明天气温时看昨天，或者看最近几天的平均；不能先看明天的实测值再说自己预测得准。

训练、验证与测试

01 / 名词定义

按时间先后划分：训练拟合权重，验证选择λ，测试评价未参与选参的未来区间。本例默认目标14–125训练、126–167验证、168–209测试。

02 / 可视化演示

每一整行代表一口井、一张图或一段时间；按独立组分配训练、验证、测试。混入同源片段会使测试看起来过于容易。时间任务还须保持先后顺序。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像考试要用没有练过的新题；把同一道题换几个数字当正式考试，可能高估实际掌握程度。

岭回归与正则强度λ

01 / 名词定义

回归用输入估计连续响应；岭回归在拟合误差之外惩罚过大的系数，减少对噪声的过度拟合。λ越大通常约束越强，不保证效果越好；本案例不是深度神经网络。

02 / 可视化演示

改变正则约束，观察拟合曲线的平滑程度。此图演示偏差与过拟合的取舍，不表示λ越大就越准确。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像用一根有弹性的尺子连散点：太松容易追着噪声拐弯，约束太强又可能错过真实趋势。

递归多步预测

01 / 名词定义

先预测下一天，把自己的预测追加到历史，再预测后一天。后续滞后特征可能含预测值，因此误差会逐步传播；不能追加真实未来值。

02 / 可视化演示

预测起点右侧用虚线表示预测。递推时把前一步预测填入后续输入；越往后越依赖自己的估计，误差可能传播。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像接龙时上一句话会成为下一句的依据，前面听错了，后面可能跟着偏。

预测、回测与未来数据泄漏

01 / 名词定义

预测时未来未知；回测时事后参考只用于打分。如果把真实未来值用于特征、标准化或选参，就产生数据泄漏，成绩可能虚高。

02 / 可视化演示

竖线左侧是已知历史，右侧是真实未来。合法预测只从左侧取输入；红色连线演示把未来真实值回送输入的错误。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像合上答案做题与先偷看答案再做题：后者分数更高，却不能证明独立解题能力。

指数递减基线

01 / 名词定义

用起点前近期产量拟合简单递减趋势，作为相同起点、相同跨度的参照；基线也不能读取未来数据，不保证每个窗口都弱于机器学习。

02 / 可视化演示

同一时间窗口下，蓝色参考与绿色模型预测对照；切换后加入粉色简单基线。应比较同一批数据的误差，模型未必总是赢。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像跑步先记下自己按匀速跑的成绩，再看新训练方法是否真的带来进步。

分布变化与跨度误差

01 / 名词定义

后期规律改变会使历史模型失配。跨度图评价15个共同起点的第h步终点误差，不等同于当前窗口内所有天的平均误差；曲线不必单调增加。

02 / 可视化演示

粉色参考在后期发生变化，绿色模型继续沿用旧规律，偏差可能扩大。示意带表示误差累积的可能性，不是经过校准的预测区间。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像按往常通勤时间出发，遇到突然修路后旧经验失效；预测越远也不保证误差每一步都单调增加。

MAE · 平均绝对误差

01 / 名词定义

把每个预测与参考值的差取绝对值，再求平均。比如误差为−2、1、3，MAE=(2+1+3)/3=2。单位与被预测的响应一致，越小越好。

02 / 可视化演示

竖线连接参考与预测，长度表示绝对误差。示例A误差1、2、3：MAE=2，RMSE≈2.16；示例B为1、2、9：MAE=4，RMSE≈5.35。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像估计到站时间：MAE关心平均差几分钟，RMSE对一次严重晚点会给出更重的惩罚。

RMSE · 均方根误差

01 / 名词定义

把误差平方后求平均，再开平方。误差−2、1、3对应RMSE=√(14/3)≈2.16。它对少数大误差更敏感；需在相同数据和单位下比较，不是准确率。

02 / 可视化演示

竖线连接参考与预测，长度表示绝对误差。示例A误差1、2、3：MAE=2，RMSE≈2.16；示例B为1、2、9：MAE=4，RMSE≈5.35。

智能化如何服务本场景？

原来难在哪里

经验外推难同时利用趋势和周期；随着预测跨度变长、后期规律变化，单一数字也难表达模型的可靠程度。

算法提供什么帮助

特征回归联合利用过去的产量信息，按时间验证后预测未来，并通过同窗口基线和滚动误差展示模型能带来的改进及失配。

仍需人工复核什么

结果仅是合成数据回测，不是产量承诺或因果解释。周期是声明的教学假设，真实部署需核验数据、漂移和区间可靠性。

动手验证：先比较21天与28天预测，再切换后期结构变化情境；对照预测、参考、基线和误差，观察优势是否仍然成立。

实际算法：滞后特征岭回归 + 递归多步预测 + 时间回测。门户归为“时序预测”；本例实际使用可解释特征回归，没有训练深度网络或提供因果归因。
