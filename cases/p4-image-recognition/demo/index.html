选择术语，在中间切换两种状态，观察图形怎样变化。所有数值和结构均为教学示意。

套管内壁图与孔眼

01 / 名词定义

把内壁图像展开观察时，孔眼表现为局部轮廓或纹理差异。图像识别寻找已有边界，不能从教学图读取真实开口尺寸。

02 / 可视化演示

把圆柱形套管内壁想象为沿纵向展开的平面；深色椭圆是教学孔眼，图像横向位置与竖向位置对应不同方向。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像把饮料罐的标签剪开铺平，再在平面上标出罐壁上的开口。

像素分割与前景掩码

01 / 名词定义

分割给每个像素一个类别；前景是孔眼，背景是其余表面。掩码用0/1记录类别，区别于只给整幅图一个标签的分类。

02 / 可视化演示

掩码给每个位置一个0或1标签：本任务中1表示孔眼前景，0表示背景。二值标签与输入图像中的明暗数值是两份不同的信息。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像在透明胶片上标出需要关注的格子，再把胶片叠回原图；胶片说明位置，原始数值仍是另一份信息。

灰度、局部均值与纹理

01 / 名词定义

灰度描述当前像素明暗；局部均值及标准差描述邻域背景和变化。本例读取5×5邻域，联合特征分割比单一全局阈值多了一层上下文。

02 / 可视化演示

灰度表示单像素明暗；局部均值参考周围窗口；纹理描述邻域变化。不同特征共同帮助区分孔眼与背景。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像辨认一块布：不只看一个点的颜色，还看附近整体深浅和纹路是否粗糙。

逻辑回归与概率阈值

01 / 名词定义

逻辑回归将特征的线性组合通过sigmoid变成0–1输出。超过阈值判前景；本例使用加权训练，输出没有进行概率校准。

02 / 可视化演示

S形曲线把特征得分映射为0–1的像素概率；水平虚线是判定阈值。提高阈值后被判为前景的范围缩小，不代表模型重新训练。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像调门禁的严格程度：门槛提高后通过的人更少；门槛和对每个人的评分是两件事。

IoU与Dice

01 / 名词定义

IoU=前景交集/前景并集；Dice=2TP/(2TP+FP+FN)。二者关注前景重叠，避免大量背景像素掩盖孔眼错误。

02 / 可视化演示

绿色框为参考区域，粉色框为预测区域。IoU=交集/并集，Dice=2×交集/(参考面积+预测面积)，都是区域重叠指标。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像两个人各自圈出同一张照片中的目标，圈的地方越重合，区域一致性就越高。

误检FP与漏检FN

01 / 名词定义

误检是把背景当孔眼；漏检是把孔眼当前景以外的区域。二者需分别看位置，较高阈值通常减少前景，但未必改善总体重叠。

02 / 可视化演示

绿色为命中TP，粉色为多圈的FP，蓝色为漏掉的FN。阈值改变会移动误检与漏检的取舍，不能只看预测区域有多大。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像筛选坏苹果：把好苹果挑走是误检，把坏苹果留在筐里是漏检。

连通区域与小区过滤

01 / 名词定义

四邻域上下左右相邻的前景形成区域。删除小区可去噪，也可能删掉真实小目标；这是明确的后处理规则，不是另一个学习模型。

02 / 可视化演示

边相接的格子组成四连通区域；示例移除面积小于3格的孤岛。过滤可能去噪，也可能误删真实小孔眼。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像清扫桌面时保留大块拼图、扫走小碎屑，但碎屑里也可能混着有用的小零件。

按整图划分

01 / 名词定义

训练、验证、测试按整幅图分开，避免同一幅图相邻像素进入不同集合导致成绩虚高。合成参考掩码只作监督或评价，不是查询输入。

02 / 可视化演示

每一整行代表一口井、一张图或一段时间；按独立组分配训练、验证、测试。混入同源片段会使测试看起来过于容易。时间任务还须保持先后顺序。

可切换的教学示意 · 数值不代表当前案例运行结果

03 / 简单易懂的类比

像考试要用没有练过的新题；把同一道题换几个数字当正式考试，可能高估实际掌握程度。

智能化如何服务本场景？

原来难在哪里

人工逐图勾边费时，单一灰度阈值容易受噪声、背景明暗与模糊影响。

算法提供什么帮助

像素分类联合灰度与邻域特征形成概率图；掩码、参考轮廓与错误图把每次识别变成可检查的结果。

仍需人工复核什么

合成图与真实成像纹理可能不同。概率未经工程校准，后处理也可能删掉小目标；输出需要图像质量与人工复核。

动手验证：切换低信噪比，再提高前景阈值，观察前景数量、误检与漏检怎样改变；悬停图像读取单个像素的计算。
