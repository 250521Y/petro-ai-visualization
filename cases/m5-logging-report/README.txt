录井报告自动生成
版本 4.0.0 / 2026-11-03

实际方法：字段词典实体抽取＋模板生成与一致性规则
What：用显式词典与正则抽取井号、深度、岩性等字段，再生成带来源的固定格式初稿。
Why：实体抽取与模板生成能减少重复录入，并把每句话追溯到原始字段。
How：解析原始记录得到7个字段，检查缺项与深度冲突；模板只引用已抽取字段，缺项显示待补，句子给出来源。

动手验证：切换完整与缺项记录，查看缺失字段提示及句子来源。

源代码目录内，直接打开 demo/index.html，公共计算与界面位于 assets/lab。正式独立ZIP已自动包含公共运行文件，解压即可独立打开。
全部数据与工况为教学合成或虚构。输出仅为待审核初稿。本例不直接生成现场设计、控制或处置指令。
