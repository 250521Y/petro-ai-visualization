落物打捞工具智能选型
版本 4.0.0 / 2026-11-03

实际方法：显式知识规则筛选＋属性相似度检索
What：将落物形态、可抓取位置和通径条件组织为可见规则，先筛适用再检索相似候选。
Why：显式知识规则先筛适用性，再用属性相似度检索案例，便于解释排除原因。
How：建立4种抽象工具，逐条验证三项硬条件；不满足的候选给出排除原因，剩余候选按属性距离排序。

动手验证：改变落物形态与井眼限制，检查候选被保留或排除的原因。

源代码目录内，直接打开 demo/index.html，公共计算与界面位于 assets/lab。正式独立ZIP已自动包含公共运行文件，解压即可独立打开。
全部数据与工况为教学合成或虚构。显式知识规则不代表真实工具标准。本例不直接生成现场设计、控制或处置指令。
